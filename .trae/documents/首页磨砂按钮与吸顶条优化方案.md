# 首页磨砂按钮与吸顶条优化方案

## 一、Summary

按用户确认的语义实施三处视觉调整：

1. **删除吸顶"半透明条"**：滚动吸顶后，搜索条不再有整条半透明背景，底部 1px 分隔线与投影也一并删除（用户选择"背景+分隔线都删"），只留搜索胶囊本身悬浮在顶部。
2. **所有按钮默认磨砂态**（鼠标移上前的状态），统一使用用户给定值：
   - 背景色 `rgba(255,255,255,0.15)`
   - 模糊 `blur(30px)`，饱和度 `saturate(100%)`（无增强）
   - 边框 `1px solid rgba(255,255,255,0.2)`
   - **hover 后恢复"本次修改之前的白色玻璃样式"**（用户确认：悬停后变成之前的白色玻璃效果 → 即现有 `--glass-bg-strong` 白玻璃 + `--glass-blur` 20px / `--glass-saturate` 180% / `--glass-border`）。
   - 覆盖按钮范围：搜索按钮、引擎选择按钮、返回顶部按钮、左上导航胶囊中的链接（首页/关于/申请收录）。
3. **搜索框背景不透明度 25%**（用户确认指背景白 25%）：搜索胶囊容器背景 `rgba(255,255,255,0.25)`，并沿用同套磨砂处理（`blur(30px) saturate(100%)` + `1px solid rgba(255,255,255,0.2)`），与按钮 15% 形成层级区分（搜索区更明显）。

## 二、Current State Analysis（现状）

- `src/views/frontend/HomeView.vue` `.search-shell.stuck`（scoped CSS）：`max-width:none + background:var(--glass-bg-strong) + border-bottom:1px solid var(--glass-border) + box-shadow` —— 即当前"半透明条 + 分隔线"。
- `src/components/frontend/SearchBox.vue`：搜索胶囊容器用 `.glass` 类（白 12%、blur 20px、saturate 180%、边框 0.18）；"搜索"按钮是**内联样式** `background:var(--glass-bg-strong)` + `border-left` + `hover:opacity-85`（内联样式无法做平滑 hover 背景过渡，且不符合按钮统一磨砂体系）。
- `src/style.css`：
  - `.glass-chip`（引擎按钮）：默认 `background:var(--glass-bg)`（12%）、边框透明、`blur 20px / saturate 180%`。
  - `.glass / .glass-card / .glass-strong / .glass-strip`：旧玻璃体系（不动，卡片/页脚保持现状，仅"按钮"与新搜索框按新规格）。
- `src/components/frontend/BackToTop.vue`：`bg-blue-600 hover:bg-blue-700` 纯蓝实底（与磨砂体系不协调，必须纳入改造）。
- `src/views/frontend/FrontendLayout.vue`：导航胶囊内 `.pill-link` 透明底 + `.pill-link:hover` 用 `var(--glass-hover)`，链接默认无磨砂底。

## 三、Proposed Changes（逐文件）

### 1. `src/style.css` — 新增按钮磨砂/搜索框样式、改造 `.glass-chip`

**新增 `.btn-glass`（按钮统一磨砂态 + 悬停回白色玻璃）**：

```css
/* 按钮默认磨砂态（鼠标移上之前） */
.btn-glass {
  background: rgba(255, 255, 255, 0.15);
  border: 1px solid rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(30px) saturate(100%);
  -webkit-backdrop-filter: blur(30px) saturate(100%);
  transition: background 0.25s ease, border-color 0.25s ease;
}

/* hover：恢复本次修改之前的白色玻璃样式 */
.btn-glass:hover {
  background: var(--glass-bg-strong);
  border-color: var(--glass-border);
  backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
}
```

**新增 `.search-glass`（搜索框背景白 25%，同套磨砂处理）**：

```css
.search-glass {
  background: rgba(255, 255, 255, 0.25);
  border: 1px solid rgba(255, 255, 255, 0.2);
  border-radius: 16px;
  box-shadow: var(--glass-shadow);
  backdrop-filter: blur(30px) saturate(100%);
  -webkit-backdrop-filter: blur(30px) saturate(100%);
}
```

**改造 `.glass-chip`（引擎按钮）**：默认态改为磨砂规格（背景 `rgba(255,255,255,0.15)`、边框 `1px solid rgba(255,255,255,0.2)`、`blur(30px) saturate(100%)`）；hover 改为白色玻璃（同 `.btn-glass:hover` 取值）；**选中态 `.glass-chip.active` 保留现有更强的高亮**（`background:var(--glass-selected)` + `border:var(--glass-border)` + 内描边投影），保证选中项明显可辨、右键风格统一。`transition` 保持 0.25s。

### 2. `src/components/frontend/SearchBox.vue`

- 搜索胶囊容器：`class="glass flex items-center rounded-full overflow-hidden"` → `class="search-glass flex items-center rounded-full overflow-hidden"`（25% 白磨砂）。
- "搜索"按钮：删除内联样式 `style="background: var(--glass-bg-strong); border-left: 1px solid var(--glass-border)"` 与 `hover:opacity-85`，改用 `btn-glass` 类（默认磨砂，hover 回白色玻璃）。

### 3. `src/components/frontend/BackToTop.vue`

- 按钮类从 `bg-blue-600 text-white ... hover:bg-blue-700 transition-all duration-200` → `btn-glass text-white transition-all duration-200`（保留 `fixed bottom-6 right-6 w-10 h-10 rounded-full shadow-lg z-50` 等布局类），删除蓝色实底。

### 4. `src/views/frontend/FrontendLayout.vue`（导航胶囊链接）

- 三个导航链接（首页/关于/申请收录）：在现有 `pill-link glass-link px-2.5...` 基础上**追加 `btn-glass` 类**（默认磨砂底 15% → hover 白色玻璃）。
- scoped 样式里 `.pill-link:hover { background: var(--glass-hover) }` 与 `.btn-glass:hover` 冲突：删除 `.pill-link:hover` 的 background 覆盖，交由 `.btn-glass:hover` 统一处理（保留圆角与过渡属 `pill-link`）。
- Logo/站名项保持原样（是品牌标识，非按钮）。

### 5. `src/views/frontend/HomeView.vue` — 删除吸顶半透明条

- `.search-shell.stuck` 规则删减为**仅宽度变化**：`max-width:none`（吸顶变通栏，胶囊居中），**删除** `background`、`border-bottom`、`box-shadow` 三项（背景+分隔线都删，符合确认结果）。
- `.search-shell` 基础规则同步精简：删除已无意义的 `background-color/border-color/box-shadow` 过渡，保留 `transform: translateZ(0)` / `will-change`（GPU 层稳定）与宽度瞬时切换；吸顶时再无背景层 → 视觉上"只剩搜索胶囊悬浮"，天然最流畅（无任何背景动画）。

## 四、Assumptions & Decisions（假设与决策）

1. "按钮悬停后变成修改之前的白色玻璃样式"：统一取现有 `.glass-strong` 取值（`--glass-bg-strong` + `--glass-border` + `--glass-blur` 20px / `--glass-saturate` 180%）作为所有按钮 hover 态；引擎芯片 hover 亦用同一取值（其原 hover 为 0.18，差异微小，统一更干净）。
2. 新磨砂数值（0.15 / 0.2 / 0.25）按用户给定字面值在浅色与深色主题下保持一致（白色霜雾在深色背景上同样成立），hover 态继续跟随主题变量。
3. "所有按钮"范围 = 搜索按钮、引擎选择按钮、返回顶部按钮、导航胶囊内三个链接；链接卡片 LinkCard、页脚、背景装饰不属按钮，保持现状。
4. `.glass-chip` 选中态保留高亮（选中必须可辨），高亮值不套 15% 磨砂。
5. 仅样式层改动，无功能/布局结构变更（吸顶小时间、引擎收起、sticky 机制等不变）。

## 六、Verification（验证步骤）

1. `node_modules/.bin/vue-tsc -b` 零错误；`node_modules/.bin/vite build` 构建成功。
2. 浏览器走查（本地 preview）：
   - 首屏所有按钮默认态计算样式 = `rgba(255,255,255,0.15)` + `blur(30px)` + `saturate(100%)` + `1px solid rgba(255,255,255,0.2)`；搜索胶囊 = `rgba(255,255,255,0.25)`。
   - 悬停任意按钮：背景变为白色玻璃（`--glass-bg-strong`），模糊回 20px/180%。
   - 向下滚动吸顶：搜索框通栏变宽但**无半透明底条、无分隔线、无白色底条**，仅胶囊悬浮；右上日期时间淡出、小时间常驻仍正常。
   - 返回顶部按钮不再是蓝色实底；引擎按钮选中高亮可辨。
   - 浅色/深色主题正常；Console 无 JS 报错（Supabase 占位网络错误可忽略）。

## 七、Out of Scope

- 不调整 `.glass / .glass-card / .glass-strip` 等既有玻璃类（卡片、页脚、背景保持现状）。
- 不改搜索逻辑、主题变量体系整体、后台界面。
