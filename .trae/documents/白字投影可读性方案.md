# 白字可读性保障方案（去磨砂后浅色背景图不糊字）

## 概述（Summary）

回答用户疑问并落地解决方案：磨砂效果（backdrop-filter）确实是低配/滚动卡顿的主要来源，而"白字在浅色背景图上看不清"不依赖磨砂也能解决——**采用参考项目 lylme_spage 的文字投影（text-shadow）手法**（其 `h2.title`、`.nav-link`、`#show_time` 均用投影保证图片/视频背景上的白字可读），为所有玻璃白字统一加柔和深色投影，并将背景图蒙层稍作增强。这样滚动中/低配设备上完全可以放心关闭 blur，白字无论背景图多浅都清晰，且投影不随滚动重算、零流畅度成本。

## 现状分析（Current State）

- 白字体系 `glass-text` / `glass-text-soft` / `glass-text-faint`（[style.css](file:///workspace/src/style.css)）共在 8 个文件 16 处使用（首页标题、分组名、卡片标题/描述、日期时间、导航按钮、About/Apply 正文、页脚等）。
- 现在浅色背景图下的可读性依赖两层：卡片/胶囊的半透明白底 + `backdrop-filter` 磨砂；一旦为流畅度关闭 blur（`html[data-scrolling]` 滚动中、`html[data-low-end]` 低配静态），白字在浅色图上的对比度就只剩背景图蒙层 `rgba(10,15,40,0.35)`（[BackgroundImage.vue](file:///workspace/src/components/frontend/BackgroundImage.vue) L29）。
- 参考项目 lylme_spage（template/default/css/style.css）核心做法正是 **text-shadow**：`h2.title{text-shadow:1px 1px 8px #504b4b}`、`.nav-link{text-shadow:0px 1px 0px #000}`，且其 `.mylist` 的 `backdrop-filter` 被注释、底色用 90% 白——白字可读完全由投影+底色保证。

## 变更方案（Proposed Changes）

### 1. `src/style.css` —— 全局白字投影

- 在 `:root, [data-theme='light']` 与 `[data-theme='dark']` 两处变量区各新增投影变量：

```css
--glass-text-shadow: 0 1px 2px rgba(0, 0, 0, 0.5), 0 0 8px rgba(0, 0, 0, 0.18);
```

- 给三个白字工具类统一应用：

```css
.glass-text,
.glass-text-soft,
.glass-text-faint {
  text-shadow: var(--glass-text-shadow);
}
```

- 补充带半透明底的交互元素（无 blur 时也是白字）：`.glass-chip`、`.btn-glass`、`.search-glass` 追加同样的 `text-shadow`，保证搜索框/引擎胶囊/搜索按钮的白字在任何背景上可读。
- 说明：投影是静态栅格，不随滚动重算，滑动流畅度不受影响；默认暗色渐变背景上投影几乎不可见，观感与现在一致。

### 2. `src/components/frontend/BackgroundImage.vue` —— 蒙层增强

- 有背景图时的暗色蒙层 `rgba(10, 15, 40, 0.35)` → `rgba(10, 15, 40, 0.45)`，进一步托底浅色图上的白字对比度（仅在有背景图时生效，默认渐变背景无影响）。

### 3. 保持不变

- 滚动降级（`html[data-scrolling]`）、低配静态降级（`html[data-low-end]`）、`useScroll`、`content-visibility`、图标懒加载、背景层提层——全部保留，不做任何回退。
- 暗色主题下的卡片底色、磨砂数值不改；投影与磨砂可共存（高配设备既有磨砂又有投影，投影在其上依然有益）。

## 假设与决策（Assumptions & Decisions）

- 用户已确认采用「白字 + 文字投影」方案（而非亮图切深字）。
- 投影强度取柔和档（1px 轴向 + 8px 弥散，黑 0.45/0.18 透明度），保证可读同时不显脏、不遮字。
- 蒙层 0.35→0.45 是配套微调：只影响"有背景图"场景，默认暗色渐变（无 bgUrl）完全不变。
