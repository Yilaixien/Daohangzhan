# 首页顶部导航与日期时间简化改造（去玻璃胶囊、去滚动动画）

## 概述（Summary）

按用户确认的方案调整前台顶部导航与日期时间区：删除左上角"上网导航"标题文字，将导航从`fixed`悬浮玻璃胶囊改为**页面流内普通行**（类似"常用导航"分类标题，吸附于页面、不滚动隐藏、无移动动画），按钮字体统一为原标题的粗体白字；日期时间去除滚动淡出动画并删除吸顶小时间显示；继续保留搜索胶囊吸顶宽度过渡等其余效果。

## 现状分析（Current State）

- [FrontendLayout.vue](file:///workspace/src/views/frontend/FrontendLayout.vue)（L6-27）：左上角 `<header class="fixed top-4 left-4 z-40 glass rounded-full transition-all duration-500">` 玻璃胶囊，内含 logo、标题 span（`text-base font-bold glass-text`）、三个 `btn-glass` 半透明按钮（`text-xs sm:text-sm`）；滚动时随 `navHidden`（L69，`scrollY > 64`）执行 `translateY(-150%)` 上移淡出（`.nav-hidden`，L87-91）。

- [HomeView.vue](file:///workspace/src/views/frontend/HomeView.vue)：

  - L6-11 右上日期时间包裹层 `fixed top-5 right-5` + `transition-all duration-500` + `:class="scrolled ? 'opacity-0 -translate-y-4' : 'opacity-100'"`（滚动淡出动画）。

  - L23-31 吸顶小时间 `<Transition name="fade"><span v-if="scrolled">…timeStr</span></Transition>`（滚动后出现在搜索胶囊右侧），配套 `.fade-*` 样式 L154-163；`timeStr` 来自 `useDateTime()`（L106）。

  - `scrolled` / `stuckAt` / `measure()`（L109-126）仍用于驱动搜索区 `.stuck` 吸顶宽度过渡，**保留**。

- About/Apply 页内容容器自带 `py-8` 上内边距，流式导航行加入 `main` 顶部不会破坏其布局。

## 变更方案（Proposed Changes）

### 1. `src/views/frontend/FrontendLayout.vue` —— 导航改为流式普通行

- 删除整个 `<header>` 玻璃胶囊（含 `fixed`、`glass`、`rounded-full`、`transition-all duration-500`、`:class="navHidden && 'nav-hidden'"`）。

- 在 `<main>` 顶部、`<slot />` 之前插入一行流式导航（与"常用导航"标题同款容器对齐方式）：

```html
<main class="flex-1 relative z-10">
  <!-- 顶部导航：页面流内普通行，随页面滚动、无玻璃背景、无隐藏动画 -->
  <div class="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 pt-6 pb-3 flex items-center gap-4">
    <router-link v-if="siteLogo" to="/" class="flex items-center shrink-0">
      <img :src="siteLogo" alt="Logo" class="h-7 w-7 rounded-full object-contain" />
    </router-link>
    <nav class="flex items-center gap-5 sm:gap-6">
      <router-link
        v-for="item in navItems"
        :key="item.path"
        :to="item.path"
        class="glass-text text-base font-bold leading-none transition-opacity hover:opacity-75"
      >
        {{ item.label }}
      </router-link>
    </nav>
  </div>
  <slot />
</main>
```

- 按钮字体与"上网导航"标题一致：`text-base font-bold glass-text`（原标题样式），移除 `btn-glass`（半透明玻璃背景）、`glass-link`、`text-xs sm:text-sm`。

- 脚本：删除 `navHidden` computed、`computed` 与 `useScroll` 导入（`scrollY` 无其他消费者）；`import { ref, onMounted } from 'vue'`。

- 样式：删除 `.nav-hidden` 规则与 header 相关过渡；`.pill-link` 不再被引用则一并删除。

### 2. `src/views/frontend/HomeView.vue` —— 日期时间去动画、删除吸顶小时间

- L6-11 日期时间包裹层：删除 `transition-all duration-500` 与 `:class="scrolled ? …"`，保留固定定位与 `select-none pointer-events-none`（恒显，不随滚动变化）。

- 删除 L23-31 吸顶小时间 `<Transition><span v-if="scrolled">` 整块。

- 脚本：删除 `import { useDateTime }` 与 `const { timeStr } = useDateTime()`（该页不再需要时间文本）。

- 样式：删除 `.fade-enter-active` / `.fade-leave-active` / `.fade-enter-from` / `.fade-leave-to` 四条（已无引用）。

- `scrolled` / `stuckAt` / `measure()` / resize 监听全部保留（仍驱动搜索区吸顶宽度过渡与 SearchBox `:stuck`）。

### 3. 首页首屏留白补偿（配合流式导航）

- 原首屏 `<section class="relative px-4 sm:px-6 pt-28 sm:pt-32 pb-4">` 的 pt 是按悬浮胶囊悬浮于其上的布局设计的；导航改为流式后顶部占用约 60px，为避免搜索区被过度下推、保持"链接无需滚动即可见"，将 `pt-28 sm:pt-32` 调整为 `pt-14 sm:pt-16`。

### 4. 保持不变

- 搜索胶囊吸顶宽度过渡、chips 收起、返回顶部按钮、`useScroll`、背景层（渐变/极光/背景图）一律不动。

## 假设与决策（Assumptions & Decisions）

- "删除背景中的半透明按钮（左上角导航胶囊）" = 去掉胶囊的玻璃（半透明背景/阴影/模糊）样式并改为页面内普通导航行；同时用户确认**不随滚动隐藏**——因此彻底删除 `navHidden` 逻辑、导航常驻页面顶部。

- "吸附在页面上不移动，和'常用导航'这些字类似" = 导航行置于页面流内（`main` 顶部），随页面自然滚动、无独立移动/隐藏动画，视觉与分类标题一致。

- 若配置了站点 logo（`config.logo`）则保留在导航行左侧作为首页入口；未配置时不占位。

- 日期时间仍保持右上角固定位置不变，仅移除滚动淡出动画。

- 首页 hero 上留白的微调是流式导航的必要伴随调整，未改变其余间距。
