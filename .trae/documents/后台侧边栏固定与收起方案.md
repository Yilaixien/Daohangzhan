# 后台侧边栏固定与收起方案

## 摘要

将后台管理界面（`AdminLayout.vue`）的左侧侧边栏改为「应用外壳」布局：外层容器固定为视口高度（`h-screen overflow-hidden`），侧边栏常驻左侧，仅右侧内容区内部滚动；同时新增一个收起/展开切换按钮，侧边栏可在 `w-56`（展开，224px）与 `w-16`（收起，64px 图标精简态）之间平滑切换。侧边栏始终处于 flex 文档流中接管宽度变化，不遮挡、不挤压主内容区。

## 现状分析

- 布局文件：[src/views/admin/AdminLayout.vue](file:///workspace/src/views/admin/AdminLayout.vue)
  - 根容器：`min-h-screen flex bg-gray-100` → 页面高度随内容增长，整体（含侧边栏与顶栏）随 body 滚动，侧边栏滚动后即消失。
  - 侧边栏 `<aside>`：`w-56 ... flex-shrink-0`，普通流内元素，无粘性/固定。
  - 顶栏 `<header>`：`h-14`，无 `flex-shrink-0`。
  - 主内容 `<main>`：`flex-1 p-6 overflow-auto`，但父容器未限高，故其内部滚动实际不生效（由 body 滚动接管）。
- 样式体系：Tailwind CSS v4（`style.css` 中 `@import "tailwindcss"`），支持任意属性类 `transition-[width]`。
- 后台各子页面（LinksView / CategoriesView / ApplyManageView / SearchEnginesView 等）的弹窗均为视口 `fixed inset-0`，表格表头 `sticky` 均位于各自内部滚动容器内，**不依赖 body 滚动**——将滚动收敛到主内容区不会破坏任何子页面。

## 变更内容

全部改动仅集中于 [src/views/admin/AdminLayout.vue](file:///workspace/src/views/admin/AdminLayout.vue)（模板 + 脚本），无需改动样式表、路由或其他文件。

### 1. 外壳改为固定视口高度（侧边栏常驻）

- 根容器：`min-h-screen flex bg-gray-100` → `h-screen flex overflow-hidden bg-gray-100`。此后仅主内容区内部滚动，侧边栏（及顶栏）始终停留在视口内。
- `<aside>`：增加 `h-full`，并叠加宽度切换：`transition-[width] duration-300 ease-in-out` + `:class="isCollapsed ? 'w-16' : 'w-56'"`。
- 主内容 `<div>`：在 `min-w-0` 基础上增加 `min-h-0`，保证 `flex-1` 能收缩、`main` 的 `overflow-auto` 内部滚动真正生效。
- `<header>`：增加 `flex-shrink-0`，防止纵向空间不足时被压缩。

### 2. 收起/展开切换按钮

- 在 Logo 行（`h-14` 顶部条）右侧新增 `<button>`，`@click="isCollapsed = !isCollapsed"`。
  - 展开态显示 `◀`，收起态显示 `▶`。
  - 附加 `:title` / `:aria-label`（收起侧边栏 / 展开侧边栏），便于可访问性与提示。
  - 展开时该行布局 `justify-between px-4`（Logo 在左、按钮在右）；收起时改为 `justify-center`，Logo 用 `v-show="!isCollapsed"` 隐藏，仅居中显示按钮。

### 3. 侧边栏各分区适配收起态（精简图标模式）

统一规则：收起时隐藏文字、菜单项水平居中、图标固定宽度对齐，并加 `:title` 悬浮提示，避免误点或无法辨认。

- 导航菜单项：
  - 图标 `<span>`：定为 `w-6 text-center shrink-0`，仅在展开时保留 `mr-3`。
  - 文字 `<span v-if="!isCollapsed">` 收起时不渲染。
  - 收起时链路 class 追加 `justify-center px-0`；`:title="isCollapsed ? item.label : undefined"`。
- 底部「返回前台」「退出登录」两项：采用与菜单项相同的规则（图标 `w-6 text-center`、收起时 `justify-center`、文字 `v-if` 隐藏、`:title` 提示），按钮保持 `w-full`。

### 4. 状态逻辑

- 脚本区新增：`const isCollapsed = ref(false)`（仅页面会话内内存态，不持久化，保持最小实现）。

## 假设与决策

- **采用「应用外壳」而非 `sticky`**：`sticky` 依赖 body 滚动且侧边栏内容超高时管理复杂；外壳方案是后台管理 UI 的标准做法，滚动行为最可控。
- 收纳宽度取 `w-16`（64px，仅图标），展开保留原 `w-56`。
- 收起状态不写 localStorage（用户未要求持久化，避免过度设计）。
- 附带效果：应用外壳下顶栏亦不再滚走、始终保持可见，属布局自然收敛，不影响任何子页面（已核对各后台页面无 body 滚动依赖）。

## 验证步骤

1. `npm run dev` 启动本地开发服务器，登录后台（`/admin`）。
2. 在内容较长的页面（如链接管理、收录审核）纵向滚动：侧边栏始终固定在左侧，不随滚动消失；顶栏同样常驻。
3. 点击收起按钮：侧边栏平滑收窄至图标态（宽度 224px → 64px），主内容区宽度自动扩展、无遮挡、可正常操作；再次点击恢复展开，动画平滑。
4. 在展开/收起两种状态下逐一点击各导航项（仪表盘、链接管理、分组管理、收录审核、搜索引擎、站点配置、主题管理）与「返回前台」「退出登录」，功能与跳转正常；收起态下悬浮显示文字提示。
5. 弹窗类操作（如链接管理的新增/编辑弹窗、删除确认）在收起/展开两种状态下均正常居中显示与操作。
6. `npm run build`（含 `vue-tsc -b` 类型检查）通过。
