# 搜索吸顶流畅度优化与后台主题管理模块

## 一、Summary

两件事：

1. **前台**：滚动吸顶时搜索框的形态变换不流畅。当前 `.search-shell.stuck` 的变宽是**瞬时切换**（`max-width: none` 无过渡），`SearchBox` 内部宽度也在吸顶瞬间跳变、吸顶小时间瞬间出现 —— 观感生硬。方案：为宽度/内边距补上平滑过渡（sticky 定位本身无跳变，补齐形变过渡即可），吸顶小时间加淡入淡出。
2. **后台**：按现有模块规范新增「**主题管理**」模块（侧边栏新菜单 + 独立页面 + 路由），用于"前台主题（毛玻璃浅色/深色）"的选择与保存即生效；并将原散落在「站点配置」里的「前台主题」下拉**收敛到该模块**（单一入口，保持整洁）。

## 二、Current State Analysis（现状）

- `src/views/frontend/HomeView.vue`（scoped）：
  - `.search-shell { position: sticky; top:0; z-index:40; max-width:42rem; margin:0 auto; padding:12px 16px; transform:translateZ(0); will-change:transform; }`
  - `.search-shell.stuck { max-width:none; }` —— **无任何 transition，宽度瞬时跳变**。
- `src/components/frontend/SearchBox.vue` 根节点：`:class="stuck ? 'max-w-3xl pr-20' : 'max-w-2xl'"`，吸顶时宽度类瞬间切换（已无 `transition-all`）；引擎行有 `transition-all duration-500` 收起动画；吸顶小时间在 `HomeView` 中 `v-if="scrolled"` 直接出现（无过渡）。
- 后台模块规范（以 `SearchEnginesView.vue`、`ConfigView.vue` 为参照）：
  - 页面外层 `<div>` → 标题 `<h2 class="text-xl font-semibold text-gray-800 mb-6">` + 白色卡片 `bg-white rounded-lg shadow-sm` + 蓝色主按钮 `bg-blue-600 text-white rounded-lg` + 表单控件统一 `border-gray-300 rounded-lg text-sm focus:ring-blue-500`，保存后跳提示并应用。
  - 侧边栏菜单：`AdminLayout.vue` `menuItems` 数组（path/label/icon）；路由：`router/index.ts` `/admin` 的 children，`meta:{ requiresAuth:true }`。
  - 主题数据源与立即生效逻辑已在 `stores/theme.ts`（`apply/syncFromConfig`）与 `ConfigView`（保存后 `useThemeStore().apply(config.theme)`）实现，可复用。
  - `ConfigView.vue` 当前含「前台主题」下拉（上次新增），需移除（收敛到新模块）。

## 三、Proposed Changes（逐文件）

### 1. `src/views/frontend/HomeView.vue` — 吸顶形变平滑过渡

- `.search-shell` 增加过渡（宽度/内边距/背景等，时长 ~0.45s、易用 easing）：
  ```css
  .search-shell {
    position: sticky;
    top: 0;
    z-index: 40;
    max-width: 42rem;
    margin: 0 auto;
    padding: 12px 16px;
    transform: translateZ(0);
    will-change: transform, max-width;
    transition: max-width 0.45s cubic-bezier(0.22, 1, 0.36, 1),
                padding 0.45s cubic-bezier(0.22, 1, 0.36, 1),
                opacity 0.3s ease;
  }
  .search-shell.stuck { max-width: none; }
  ```
  （sticky 定位本身无跳变；这里补的是"变宽"动画。仅单个元素一次触发，性能开销可忽略。）
- 吸顶小时间改为淡入淡出：外包 `<Transition name="fade">`（复用 `BackToTop` 的同名 fade 过渡），scoped 补 `.fade-enter-active/.fade-leave-active{transition:opacity .25s}`、`.fade-enter-from,.fade-leave-to{opacity:0}`；保留 `v-if="scrolled"` 的显隐。

### 2. `src/components/frontend/SearchBox.vue` — 内部宽度归 Shell 统一过渡

- 根节点宽度类改为**恒定** `max-w-3xl mx-auto`（吸顶/普通态一致），仅保留吸顶时的右留白：`:class="stuck ? 'pr-20' : ''"`（`pr` 切换瞬时即可，配合 Shell 的整体过渡感观连贯）；删除 `max-w-2xl` 切换，避免"外层 + 内层"双重宽度动画叠加。

### 3. 新增 `src/views/admin/ThemeManageView.vue` — 主题管理模块

参照既有模块规范实现：

- **模板**：
  - 顶部：`<h2 class="text-xl font-semibold text-gray-800 mb-6">主题管理</h2>`，附一行说明 `text-sm text-gray-400`：选择前台默认主题，保存后立即生效。
  - `bg-white rounded-lg shadow-sm p-6` 卡片：**两个主题选择卡**（毛玻璃浅色 / 毛玻璃深色），每张卡：左侧渐变预览块（浅色：#1e2a78→#5b2a9d；深色：#050816→#131031，`rounded-lg h-14 w-full` 或缩略渐变条）+ 主题名称 + 说明；选中态 `border-blue-500 ring-2 ring-blue-200`，未选中 `border-gray-200 hover:border-gray-300`，外层 `cursor-pointer`（radio 隐藏，用点击切换 `activeTheme`）。
  - 底部右对齐主按钮「保存配置」`bg-blue-600 text-white rounded-lg px-6 py-2.5`（saving 时显示"保存中..."）；保存成功右下角绿色浮层提示"配置已保存"（与 ConfigView 一致）。
  - 加载时卡片内骨架屏（`animate-pulse` + `bg-gray-200`）。
- **脚本**（与 ConfigView 同款模式）：
  - `const theme = ref<'light' | 'dark'>('light')`
  - `onMounted`: `services.config.get('theme')` 回填（缺省 light）。
  - `save()`: `services.config.set('theme', theme.value)` → `useThemeStore().apply(theme.value)` → 成功提示 2s。

### 4. `src/router/index.ts` — 新增后台子路由

在 `/admin` children 末尾（search-engines 之后）添加：
```ts
{
  path: 'theme',
  name: 'admin-theme',
  component: () => import('@/views/admin/ThemeManageView.vue'),
  meta: { requiresAuth: true },
},
```

### 5. `src/views/admin/AdminLayout.vue` — 侧边栏新增菜单

`menuItems` 末尾追加：`{ path: '/admin/theme', label: '主题管理', icon: '🎨' }`（置于「站点配置」之后）。

### 6. `src/views/admin/ConfigView.vue` — 移除原「前台主题」下拉（单一入口）

- 删除「基本信息」区块中的「前台主题」`<select>` 字段。
- 删除 `config` reactive 中 `theme: 'light'` 初始值（`configKeys` 随之不含该 key，不再写/读）。
- 删除 `useThemeStore` 引用与保存时 `useThemeStore().apply(...)` 调用（逻辑收敛到新模块）。

## 四、Assumptions & Decisions（假设与决策）

1. 吸顶"变换不流畅" = 宽度/留白瞬时跳变 + 小时间突兀出现；sticky 定位本身已平滑，无需改机制。
2. 主题管理模块为后台「独立菜单 + 独立页面」，遵循现有模块（搜索引擎/站点配置）的卡片与表单规范；主题选项维持已确认的**双主题**（毛玻璃浅色/深色）。
3. 「站点配置」里的旧主题下拉**移除**，统一由「主题管理」模块管理同一 `theme` 配置键，避免双入口（如您希望保留原下拉，可在审阅时指出，实现时保留即可）。
4. 新模块沿用既有鉴权（`meta.requiresAuth`）、数据源（config 表 `theme` 键）与前端 `data-theme` 应用机制（`useThemeStore`）。
5. 仅样表示层与后台 UI 改动，不改变功能逻辑、数据流、部署方式。
