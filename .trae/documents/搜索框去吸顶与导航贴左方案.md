# 搜索框去除吸顶动画 + 导航按钮贴左改造

## 概述（Summary）

按用户确认：删除搜索框的吸顶滚动动画，搜索框**不吸顶、随页面自然滚动**（与导航、日期时间一致）；将顶部导航行的"首页/关于/申请收录"从内容列对齐改为**视口最左侧**。改造后首页滚动时除"返回顶部"按钮外不再有任何悬浮/滚动态变化。

## 现状分析（Current State）

- [HomeView.vue](file:///workspace/src/views/frontend/HomeView.vue)：
  - L12 `<div ref="shellRef" class="search-shell w-full" :class="{ stuck: scrolled }">`：搜索区外壳 `position: sticky; top: 0`，吸顶时 `.stuck` 把 `max-width: 42rem` 过渡为通栏（L119-138）。
  - L16 给 `SearchBox` 传 `:stuck="scrolled"`，驱动其内部高度/内边距/引擎胶囊收起变化。
  - L93-116：`useScroll` + `stuckAt` 阈值 + `measure()`（resize 重测）+ `scrolled` computed 构成全部滚动逻辑。
- [SearchBox.vue](file:///workspace/src/components/frontend/SearchBox.vue)：`stuck` prop 控制 `.search-inner` 的 `pr-20`、`.search-glass` 高度（`h-12 sm:h-14` → `h-12`）、引擎胶囊 `opacity-0 max-h-0 mt-0` 收起。
- [FrontendLayout.vue](file:///workspace/src/views/frontend/FrontendLayout.vue) L9：导航行容器 `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8` 与"常用导航"分类标题同列居中。
- `useScroll` 仍有消费方（`BackToTop.vue` 的 `visible`），**保留**。

## 变更方案（Proposed Changes）

### 1. `src/views/frontend/HomeView.vue` —— 移除全部搜索滚动逻辑

- 搜索区外壳（L12）：去掉 `ref="shellRef"`、`:class="{ stuck: scrolled }"`，仅保留静态类：`class="search-shell w-full"`。
- `<SearchBox>`：去掉 `:stuck="scrolled"` 传参。
- 脚本（L82-117）：删除 `useScroll` 导入与 `const { scrollY } = useScroll()`、`shellRef`、`stuckAt`、`measure()`、`scrolled` computed、resize 监听；`onMounted` 简化为 `onMounted(() => { store.fetchData() })`（保留数据加载）；移除 `computed`、`onUnmounted` 及不再使用的 `ref` 导入（保留 `onMounted`）。
- 样式（L119-138）：`.search-shell` 移除 `position: sticky`、`top`、`z-index`、`transform: translateZ(0)`、`will-change`、`contain: paint` 与整条 `transition`（均只服务于吸顶动画），保留 `max-width: 42rem; margin: 0 auto; padding: 12px 16px` 使搜索区保持原居中窄条形态；删除 `.search-shell.stuck` 规则。

### 2. `src/components/frontend/SearchBox.vue` —— 删除 stuck 形态代码

- `defineProps` 移除 `stuck?: boolean` 及注释。
- `.search-inner`：删除 `:class="stuck ? 'pr-20' : ''"`，固定为 `class="search-inner mx-auto max-w-3xl whitespace-nowrap"`。
- `.search-glass`：删除 `:class="stuck ? 'h-12' : 'h-12 sm:h-14'"`，固定为 `class="search-glass flex items-center rounded-full overflow-hidden h-12 sm:h-14"`。
- 引擎胶囊行：删除 `:class="stuck ? …"` 条件与 `transition-all duration-500`，固定为 `class="flex justify-center flex-wrap gap-2.5 mt-4 overflow-hidden opacity-100 max-h-20"`（胶囊常显，即原非吸顶形态）。

### 3. `src/views/frontend/FrontendLayout.vue` —— 导航行贴左

- L9 导航行容器：`max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 pt-6 pb-3 flex items-center gap-4` → `px-4 sm:px-6 pt-6 pb-3 flex items-center gap-4`（去掉 `max-w-7xl mx-auto` 与 `lg:px-8`，不再与"常用导航"内容列对齐，贴视口左侧）。

### 4. 保持不变

- `useScroll` 合成、`BackToTop`（返回顶部按钮仍按滚动显示）、背景层、日期时间恒显逻辑、分组卡片的 `content-visibility` 均不动。

## 假设与决策（Assumptions & Decisions）

- 用户已确认搜索框**不吸顶**，与导航/日期一致随页面自然滚动；搜索区保持原有居中窄条视觉（`max-width: 42rem`）及完整形态（胶囊高度 `sm:h-14`、引擎选择胶囊常显）。
- 导航"最左侧"指贴视口左缘，保留最小页边距 `px-4 sm:px-6`（不进入内容列对齐）。
- 删除的 `useScroll` 相关代码仅限 HomeView；该 composable 因 BackToTop 仍在用而保留。
- "删除滚动动画"不再涉及其他元素（about/apply 页无滚动态）。

   - 顶部导航行"首页/关于/申请收录"贴视口左侧显示（不再与"常用导航"同列）；
   - 返回顶部按钮仍按滚动出现/消失（未受影响）；
   - 首页与 About/Apply 页导航行显示正常。
3. 窗口缩放、刷新无异常。
