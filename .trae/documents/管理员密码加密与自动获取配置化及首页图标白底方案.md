# 管理员密码加密 + 自动获取API配置化 + 首页图标白底 方案

## Summary
本方案处理三项优化：
1. **管理员密码安全存储**：`config.admin_pwd` 目前经 `PUT /config/:key` 明文写入数据库。开发规范（README + neon_schema.sql）要求存 bcrypt 哈希且客户端不可读，需在服务端写入时自动加密、读取时脱敏，并修复 ConfigView 空值覆盖导致密码被清空的隐患，保持登录校验逻辑不变。
2. **自动获取 API 配置化**：后台"添加链接"与前台"申请收录"的自动获取名称/图标目前硬编码 API 地址（`lianjie.hjke.cn` 名称、`a.favicon.im` 图标），改为在站点配置中单独设置 `fetch_title_api` / `fetch_icon_api` 两个地址，带默认值回退。
3. **首页图标白色底衬**：在 `LinkCard.vue` 图标区加 40px 白色圆角底衬（App 图标风格），图片内容 32px、emoji 30px、首字符兜底 16px。

## Current State Analysis
- 后端真实实现是 `edge-functions/api/[[default]].js`（Neon PostgreSQL + 函数代理）；`backend-reference/` 是 MySQL/Express 参考后端，需同步修改保持一致。
- `admin_pwd` 现状：
  - 登录校验（edge function `login()` / `auth.js`）已支持 bcrypt 比较（edge 侧用 pgcrypto.crypt，参考后端用 bcryptjs.compare）。
  - `PUT /config/:key`（edge function 第 211-218 行 / reference `config.js` 第 36-55 行）原样 upsert，明文入库。
  - `GET /config`（edge 第 201-204 行 / reference 第 6-18 行）返回全部含 `admin_pwd` 哈希。
  - neon 模式前台直连读 config 走 nav_read，RLS 已排除 `admin_pwd`（neon_schema.sql 第 125 行）；`ConfigView.vue` 的 `getAll()` 即走此路径，故输入框始终为空，但 `saveAll()`（第 155-166 行）会无条件回传 `admin_pwd:''`，会把已初始化的哈希覆盖为空 → 登录失效。**需修复**。
- 自动获取：`LinksView.vue` `autoFetch()`（第 308-342 行）硬编码 `https://a.favicon.im/{hostname}` 与 `https://lianjie.hjke.cn/api/title?url={url}`；`ApplyView.vue` `autoFetch()`（第 221-255 行）用 `${origin}/favicon.ico` + 域名推断。
- 首页图标：`LinkCard.vue` 图标区当前为 40px 透明容器 + 图片 40px / emoji 30px / 首字母 40px（上一任务设定）。

## Proposed Changes

### 1. 管理员密码加密（服务端写入加密 + 读取脱敏）

#### `edge-functions/api/[[default]].js`
- **PUT /config/:key**（第 210-218 行）：对 `admin_pwd` 特殊处理——
  - 值为空 → 不写入，直接返回（保留原哈希）；
  - 值非空 → 数据库侧 bcrypt 加密后 upsert（与登录校验同款 pgcrypto，规避边缘函数 CPU 限制）：
    ```sql
    INSERT INTO config (key, value) VALUES ('admin_pwd', crypt(${value}, gen_salt('bf', 10)))
    ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value
    ```
    返回时 `value` 置 null（不回显）。
  - 其余 key 保持原样 upsert。
- **GET /config**（第 201-204 行）：过滤掉 `admin_pwd` 行（哈希不出服务器）。
- **GET /config/:key**（第 206-209 行）：key 为 `admin_pwd` 时直接返回 `null`。
- 同步更新文件头部注释说明。

#### `backend-reference/src/routes/config.js`
- 引入 `bcryptjs`。
- **PUT /config/:key**：`admin_pwd` 空值跳过；非空 `bcrypt.hashSync(value, 10)` 后入库。
- **GET /config**、**GET /config/:key**：脱敏 `admin_pwd`（返回空/不返回）。
- `auth.js` 已用 `bcrypt.compare`，无需改动。

#### `src/views/admin/ConfigView.vue`
- `saveAll()`（第 155-166 行）：遍历保存时跳过 `admin_pwd`（空值时不再回传，杜绝覆盖）；输入框占位符"留空则不修改"保留。
- 注：neon 模式 `getAll()` 经 RLS 已不含 `admin_pwd`，rest 模式后端脱敏后亦为空，加载逻辑无需改。

#### `database/mysql_schema.sql`
- 第 204 行 `admin_pwd` 描述改为 `'管理员密码 bcrypt 哈希（服务端写入时自动加密）'`。

### 2. 自动获取 API 配置化

#### `database/neon_schema.sql` 与 `database/mysql_schema.sql`
- 在 config 种子数据新增两键：
  ```sql
  ('fetch_title_api', 'https://lianjie.hjke.cn/api/title?url={url}', '自动获取网站名称 API（{url}=URL编码占位，留空用默认）'),
  ('fetch_icon_api', 'https://a.favicon.im/{hostname}', '自动获取网站图标 API（{hostname}/{url} 占位，留空用默认）'),
  ```
- 占位符约定：`{url}` → `encodeURIComponent(完整URL)`；`{hostname}` → 域名。

#### `src/views/admin/ConfigView.vue`
- reactive config 增加 `fetch_title_api`、`fetch_icon_api` 两键（默认值为上面的默认模板）。
- 新增"自动获取设置"区块：两个输入框 + 占位符说明（"支持 {url}/{hostname} 占位符，留空使用默认服务"）。

#### `src/views/admin/LinksView.vue`
- 新增 `fetchTitleApi` / `fetchIconApi` refs，默认值 = 当前硬编码地址。
- `onMounted` 里 `loadData()` 后读取 `services.config.getAll()`，有值则覆盖 refs。
- `autoFetch()`（第 324-336 行）改为模板替换：
  - 图标：`fetchIconApi.replace(/\{hostname\}/g, hostname).replace(/\{url\}/g, encodeURIComponent(raw))`
  - 名称：`fetchTitleApi.replace(/\{url\}/g, encodeURIComponent(raw)).replace(/\{hostname\}/g, hostname)`，解析兼容 `json?.data?.title || json?.title || json?.name`。

#### `src/views/frontend/ApplyView.vue`
- `onMounted` 已加载 config，补充读取 `fetch_title_api` / `fetch_icon_api` 到 refs（默认值同上）。
- `autoFetch()`（第 221-255 行）替换 favicon.ico + 域名推断逻辑：图标用 `fetchIconApi` 模板拼 URL 直接填充；名称为空时请求 `fetchTitleApi` 获取并填入。

### 3. 首页图标白色底衬（App 图标风格）

#### `src/components/frontend/LinkCard.vue`（第 9-32 行图标区）
- 外容器（40px）：`w-10 h-10 mb-2 flex items-center justify-center` → 追加白色圆角底衬：`w-10 h-10 mb-2 rounded-xl bg-white shadow-sm flex items-center justify-center`。
- 图片：`w-10 h-10 object-contain` → `w-8 h-8 object-contain`（32px）。
- emoji：保持 `text-3xl`（30px，已达目标）。
- 首字符兜底：`w-10 h-10 rounded-lg text-sm font-bold glass-text` + 内联玻璃背景 → `w-4 h-4 rounded text-xs font-bold text-gray-500 bg-gray-100 flex items-center justify-center`（16px，白底上需深灰字，去除原玻璃样式内联 style）。
- 其余（标题/描述/hover 动效）不变。

## Assumptions & Decisions
- 仅 `admin_pwd` 加密（用户已确认）；`admin_user` 保持明文（用户名非凭据，符合现有规范）。
- 密码加密走数据库侧 `pgcrypto.crypt`（edge 函数）与 `bcryptjs`（参考后端），成本因子 10，与登录校验兼容，不改变"客户端无法读取哈希"的规范。
- `fetch_icon_api` 作为 URL 模板（保留现有"即时填图标、无网络等待"行为）；`fetch_title_api` 作为需 fetch 的接口。两者均支持 `{url}`/`{hostname}` 占位符。
- 白底衬用不透明 `bg-white`，圆角 `rounded-xl`，加 `shadow-sm` 保证浅色背景下可见。
- 不修改 README 文档（未要求）。
