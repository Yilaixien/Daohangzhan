# 全局字体样式统一方案（日期时间 → 庞门正道细线体；其余 → 阿里巴巴普惠体）

## 一、目标

1. 页面中所有**日期 / 时间相关文字**统一使用**庞门正道细线体**（`PangMenZhengDaoXiXianTi-date.woff2`）。
2. 其余所有文字（标题、正文、按钮、链接、表单等）统一使用**阿里巴巴普惠体**（`AlibabaPuHuiTi-M-cn3500.woff2`）。
3. 两种字体正确引入并加载，带合理回退链，完整覆盖所有相关文本节点，避免字体未生效或样式遗漏。

## 三、方案与改动

### 1. 字体文件落位 `src/assets/fonts/`

将上传的字体复制为（保留语义化命名）：

- `/workspace/.uploads/88c2d8df-d006-4d6f-a5d8-eed7a4656e9f_AlibabaPuHuiTi-M-cn3500.woff2` → `src/assets/fonts/AlibabaPuHuiTi-M.woff2`

- `/workspace/.uploads/b8bb4e61-7988-44e8-9dff-189bf7ec6d53_PangMenZhengDaoXiXianTi-date.woff2` → `src/assets/fonts/PangMenZhengDaoXiXianTi.woff2`

放在 `src/assets` 而非 `public`，由 Vite 处理后输出带 hash 的资源，配合 `base: './'` 生成正确相对路径，避免站/home 部署子目录时路径失效。

### 2. [src/style.css](file:///workspace/src/style.css)：@font-face + Tailwind v4 主题 + 全局兜底

在 `@import "tailwindcss";` 之后追加：

```css
/* ============ 字体体系 ============ */
@font-face {
  font-family: 'AlibabaPuHuiTi';
  src: url('./assets/fonts/AlibabaPuHuiTi-M.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: 'PangMenZhengDaoXiXianTi';
  src: url('./assets/fonts/PangMenZhengDaoXiXianTi.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@theme {
  /* 全站默认字体（覆盖 Tailwind Preflight 默认值，同时生成 font-sans 工具类） */
  --font-sans: 'AlibabaPuHuiTi', 'PingFang SC', 'Hiragino Sans GB',
    'Microsoft YaHei', 'Microsoft JhengHei', 'Helvetica Neue', Arial, sans-serif;
  /* 日期/时间专用字体工具类 font-datetime */
  --font-datetime: 'PangMenZhengDaoXiXianTi', 'AlibabaPuHuiTi',
    'PingFang SC', 'Microsoft YaHei', sans-serif;
}

@layer base {
  /* 兜底：确保 html 上全局字体必生效（覆盖前台 .glass-page 与后台灰色页面） */
  html {
    font-family: var(--font-sans);
  }
}
```

要点：

- **回退方案**：庞门正道细线体可能只收录数字/部分汉字（文件名带 `-date`），回退链首备选 `AlibabaPuHuiTi`，再备系统中文字体，保证「2026年09月03日 / 星期四 / 12:34」等字符永不缺字。

- `font-display: swap` 保证字体加载完成前先用回退字渲染，无白屏、无 FOIT。

- Tailwind v4 的 `@theme --font-*` 会生成对应 `font-*` 工具类（`font-sans`、`font-datetime`），且 `--font-sans` 会同步影响 Preflight 的 `html` 默认字体。

- 两字体均声明为单字重 `400`；`font-medium/font-semibold/font-bold` 由浏览器字体合成（font-synthesis，默认开启）加粗，无需引入多字重文件。

- 依赖 `document.fonts` 在渲染时已加载（字体为本地位小体积 woff2，数据加载后渲染时通常已就绪；未就绪时自动回退不影响功能）。

## 四、假设与决策

1. 「前端页面」理解为整个 Vue 前端应用（前台公开页 + 后台管理页），统一应用两套字体。
2. 庞门正道细线体缺失汉字时回退到阿里巴巴普惠体（回退链内已含），保证「年/月/日/星期」等字符正常显示。
3. 两种字体仅提供单字重，加粗效果依赖浏览器字体合成；如需精确字重后续可补充多字重文件（本次不做）。
4. App 标题（`index.html` `<title>`）不属页面渲染文本，不在作用范围。
5. `font-mono` 移除属严格满足「其余文字统一用阿里巴巴普惠体」的覆盖性改动；如希望保留输入区等宽显示，可仅保留验证码移除、textarea 撤销移除（可调整）。
