# 首页搜索区视觉与交互优化方案

## 一、Summary

在上一轮毛玻璃重构的基础上，微调首页搜索区：

1. **字体层级**：放大时间字号、缩小日期字号（作用在 `DateTimeDisplay`）。
2. **吸顶动画流畅度**：弃用「relative→fixed + transition-all」的旧实现，改为「`position: sticky` + 最小化动画属性 + GPU 合成层」，消除吸顶瞬间的布局跳变与滚动掉帧。
3. **首屏留白**：删除 `min-h-screen` 全屏首屏，改为自然高度的顶部留白区，保证**不滚动时下方链接即可见**。
4. **隐形阻挡层 → 分隔线**：删除滚动吸顶时下方的透明模糊长条（`.sticky-shield`），改为吸顶条自身 `border-bottom` 分隔线 + 底部柔和投影；链接由吸顶条自身的玻璃背景 + 模糊直接遮挡，不再单独占用一层 `backdrop-filter`（顺带大幅降低渲染成本）。

联网调研结论支撑（本轮允许联网搜索）：
- `backdrop-filter` 是 GPU 密集型操作，滚动时对大面积元素反复重算会掉帧；应避免动画期间触发其重绘，并利用 `transform: translateZ(0)` / `will-change: transform` 提前建立合成层。
- `position: sticky` 元素不脱离文档流，吸顶/离开吸顶不产生页面重排，是平滑吸顶的首选；`fixed` 脱离文档流会引发布局抖动。
- 动画性能黄金法则：尽量只动 `transform`/`opacity`，避免逐帧动画布局属性（`max-width`、`padding`、`box-shadow` 等）。

## 二、Current State Analysis（现状）

- `src/views/frontend/HomeView.vue`：
  - 首屏 `<section class="... min-h-screen">`，内容用 `flex justify-center` 垂直居中 → **链接必须滚动才可见**（需求 3 的最大问题）。
  - `.search-shell`：普通态 `position: relative`，吸顶态 `position: fixed; top:0`（L127-139），模板带 `transition-all duration-500`，`position` 不可动画 → **吸顶瞬间元素从约 50vh 位置瞬移到顶部，跳变明显**（需求 2 的主因）。
  - `.sticky-shield`（L142-153）：吸顶时的透明模糊阻挡层，`fixed top-0 h-72px z-30` + `backdrop-filter`，与吸顶条构成**双层 blur**，渲染成本高（需求 4 要替换）。
  - 滚动判定 `window.scrollY > 60`（L106-108），与吸顶位置不匹配。
- `src/components/frontend/DateTimeDisplay.vue`：当前日期 `text-xl sm:text-2xl`、时间 `text-sm sm:text-base`，**时间偏小**（需求 1 要放大时间、缩小日期）。
- `src/components/frontend/SearchBox.vue`：根节点 `transition-all duration-500`（动画 max-width/pr 等布局属性）+ 吸顶时 `max-w-3xl pr-20`（需求 2 涉及的次要抖动源）。
- `src/style.css`：浅色/深色两套主题里各有一个 `--glass-shield` 变量，仅供 `.sticky-shield` 使用，替换后应一并删除。

## 四、Proposed Changes（逐文件）

### 1. `src/views/frontend/HomeView.vue` — 布局重构 + sticky + rAF + 移除阻挡层

**What/How**：

- **首屏改矮**：`<section>` 由 `min-h-screen ... justify-center` 改为自然高度顶部留白区：
  `class="relative px-4 sm:px-6 pt-28 sm:pt-32 pb-4"`，内部仅保留右上固定日期时间块（不动，仍 `fixed top-5 right-5`）。不再 `justify-center/items-center`。
- **搜索区改为 sticky shell**：把 `.search-shell` 从 `section` 内部移到 section 之后、内容区之前，作为独立块：
  - 模板：`<div ref="shellRef" class="search-shell w-full" :class="{ stuck: scrolled }">`（去掉 `transition-all duration-500` 类，动画交给 scoped CSS）。
  - scoped CSS：
    ```css
    .search-shell {
      position: sticky;   /* 不脱离文档流，无布局跳变 */
      top: 0;
      z-index: 40;
      max-width: 42rem;   /* 普通态居中窄条 */
      margin: 0 auto;
      padding: 12px 16px;
      transform: translateZ(0);            /* GPU 合成层，稳定 backdrop-filter */
      will-change: transform;
      transition: background-color .35s ease, border-color .35s ease,
                  box-shadow .35s ease, opacity .35s ease;
    }
    .search-shell.stuck {
      max-width: none;                      /* 变宽：瞬时切换，避免逐帧布局动画 */
      background: var(--glass-bg-strong);
      border-bottom: 1px solid var(--glass-border);  /* 分隔线 */
      box-shadow: var(--glass-shadow);
    }
    ```
  - 吸顶条分隔线（替代原透明长条）：`border-bottom: 1px solid var(--glass-border)`；同时 `box-shadow: var(--glass-shadow)` 衬托底部柔化边缘，链接从分隔线下滑过即被吸顶条玻璃背景模糊遮挡，不会侵入搜索框区域。**删除** `.sticky-shield` 元素与其 CSS、以及模板里 `<div v-if="scrolled" class="sticky-shield">`。
  - 吸顶小时间位置不变（shell 是定位元素，可作绝对定位父容器）：`absolute right-2 sm:right-6 top-1/2 -translate-y-1/2`。
- **滚动判定改为与吸顶位置精确对齐**：监听 scroll（passive）+ rAF 合并：
  ```ts
  let ticking = false
  function handleScroll() {
    if (ticking) return
    ticking = true
    requestAnimationFrame(() => {
      ticking = false
      scrolled.value = (shellRef.value?.getBoundingClientRect().top ?? 0) <= 0
    })
  }
  ```
  吸顶类恰好在 shell 触顶的瞬间切换 → 视觉无瞬移、无跳变。
- **内容区**：`pt` 微调为 `pt-6`（减少与搜索区留白），其余不变。
- 删除 scoped 样式里 `will-change` 合并块中关于 `.sticky-shield` 的部分。

### 2. `src/components/frontend/DateTimeDisplay.vue` — 放大时间、缩小日期

**What**：仅调整字号（结构/顺序不动，日期仍在时间上方，符合此前定稿）：
- 日期行：`text-xl sm:text-2xl` → `text-sm sm:text-base font-medium`（缩小）。
- 时间行：`text-sm sm:text-base` → `text-2xl sm:text-3xl font-semibold`，保留 `tracking-[0.3em]`（加宽）与 `tabular-nums`（放大）。
- 同步更新模板注释（日期：辅助信息；时间：主视觉）。

### 3. `src/components/frontend/SearchBox.vue` — 收敛过渡属性

**What**：根节点去掉 `transition-all duration-500`（避免动画 `max-width/pr` 布局属性），保留吸顶时 `max-w-3xl pr-20` 类切换（瞬时生效，宽度由外部 shell 把控）。引擎按钮行收起动画不变。

### 4. `src/style.css` — 清理废弃变量

**What**：删除 `:root/[data-theme='light']` 与 `[data-theme='dark']` 中的 `--glass-shield` 定义（不再有消费者）。其余变量体系不动。

## 五、Assumptions & Decisions

1. 首屏高度：采用「自然高度 + 顶部留白（pt-28/32）」，搜索条随后的内容区链接在任意视口下无需滚动即可见（严格满足需求 3）。视觉上保留日期时间与搜索条构成的主视觉，不再追求首屏占满全屏。
2. 吸顶宽度变化（`max-w-2xl → 通栏`）改为**瞬时切换**（不逐帧动画 max-width），换色/边框/投影用 0.35s 过渡，二者结合是「视觉有变化、滚动极流畅」的最佳折中。
3. 分隔线方案：以吸顶条 `border-bottom` + 柔和 `box-shadow` 作为延伸分隔线，不再保留透明模糊长条与第二层 `backdrop-filter`（用户允许"其他方案代替"；性能收益显著）。
4. 日期/时间保持"日期在上、时间在下"的顺序，仅互换字号权重。
5. 不新增依赖、不改功能逻辑、不动数据流；仅样式与布局层面。
