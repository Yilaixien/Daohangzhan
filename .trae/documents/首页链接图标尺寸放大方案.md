# 首页链接图标尺寸放大方案

## Summary

用户反馈首页链接图标太小，需放大首页链接卡片中的图标尺寸。经确认，按"目标值 + 图片也调大到 40px"方案执行：图片 32px→40px、emoji 24px→30px、首字母占位底衬 32px→40px，外容器（图标区域 40px flex 容器）尺寸保持不变。

## Current State Analysis

首页链接图标渲染集中在单个组件 `src/components/frontend/LinkCard.vue`，图标区域结构如下：

- **外容器**：`<div class="w-10 h-10 mb-2 flex items-center justify-center">`（40px × 40px，透明 flex 容器）— 保持不变

- **图片分支**（URL 图标）：`<img class="w-8 h-8 object-contain">`（32px）

- **emoji 分支**（非 URL 图标）：`<div class="text-2xl group-hover:scale-110 transition-transform">`（24px）

- **首字母占位分支**（无图标/加载失败）：`<div class="w-8 h-8 rounded-lg text-sm font-bold glass-text">` + 内联背景/边框（32px，唯一带可见"底衬"背景的元素）

已确认：

- 全局样式（`src/style.css`）无影响图标尺寸的规则（仅 `.glass-chip img` 14px，作用于引擎选择按钮，与本卡片无关）。

- 根字体未改 rem 基准，Tailwind 类按标准 px 渲染：`w-10`=40px、`w-8`=32px、`text-2xl`=24px、`text-3xl`=30px。

- 首页加载骨架（`src/views/frontend/HomeView.vue` 第 37 行 `w-10 h-10 rounded-lg mb-2`）已是 40px，与新的底衬尺寸一致，无需改动。

## Proposed Changes

### 文件：`src/components/frontend/LinkCard.vue`

| 元素            | 现状                | 改动后               | 操作 |
| ------------- | ----------------- | ----------------- | -- |
| 外容器           | `w-10 h-10`（40px） | 不变                | 不改 |
| 图片 `<img>`    | `w-8 h-8`（32px）   | `w-10 h-10`（40px） | 改类 |
| emoji `<div>` | `text-2xl`（24px）  | `text-3xl`（30px）  | 改类 |
| 首字母占位 `<div>` | `w-8 h-8`（32px）   | `w-10 h-10`（40px） | 改类 |

- 图片：`class="w-8 h-8 object-contain"` → `class="w-10 h-10 object-contain"`（填满 40px 外容器）

- emoji：`class="text-2xl group-hover:scale-110 transition-transform"` → `class="text-3xl group-hover:scale-110 transition-transform"`

- 首字母占位：`class="w-8 h-8 rounded-lg text-sm font-bold glass-text"` → `class="w-10 h-10 rounded-lg text-sm font-bold glass-text"`

- 外容器与标题/描述部分保持原样。

## Assumptions & Decisions

- 按用户选择"图片也调大到 40px"执行：图片、首字母底衬统一为 40px，外容器保持 40px（无额外留白）。

- emoji 30px 使用 Tailwind `text-3xl`（1.875rem = 30px），与用户指定 30px 精确一致。

- 不涉及其他文件：`HomeView.vue` 骨架占位、管理端预览、搜索框图标均不在本次范围内。

## Verification

1. 运行开发服务器，打开首页，确认：

   - URL 图标的图片显示为 40px，充满图标区

   - emoji 图标字号约 30px

   - 无图标链接显示 40px 首字母占位底衬
2. 检查 `npm run build`（或 `vue-tsc`）无类型/构建错误。
3. 快速肉眼确认卡片布局无溢出（40px 图标在 40px 容器内，卡片 padding 不变）。
