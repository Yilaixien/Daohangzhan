# 首页毛玻璃风格重构方案

## 一、Summary

以「毛玻璃（Glassmorphism）」为默认视觉语言，完全重构前台首页及其公共布局，并新增浅色/深色双主题系统。改动**仅限样式与布局层面**，不涉及功能逻辑、数据流与后端。部署保持兼容腾讯云 EdgeOne Pages（`base:'./'` + Hash 路由 + `VITE_*` 环境变量，无新增硬编码）。

关键决策（已与用户确认）：
- 主题 = **双主题**：毛玻璃浅色（默认）+ 毛玻璃深色。
- 主题切换入口放在 **/admin → 站点配置（设置面板）** 中（新增「前台主题」下拉），前台不再放置切换按钮。
- 玻璃变量体系（按需求给定的默认值）：背景 `rgba(255,255,255,0.12)`、边框 `rgba(255,255,255,0.18)`、模糊 `20px`、饱和度 `180%`、投影 `0 8px 32px rgba(0,0,0,0.12)`、文字 `#ffffff`。

## 二、Current State Analysis（现状）

技术栈：Vue 3 + TypeScript + Vite 8 + Tailwind CSS v4 + Pinia，Hash 路由，`base:'./'`，构建产物 `dist/` 直接适配 EdgeOne Pages。环境变量统一走 `import.meta.env.VITE_*`（见 `src/services/supabase/index.ts`），无硬编码。

涉及文件现状：
- `src/views/frontend/FrontendLayout.vue`：顶部**全宽横向导航条**（`sticky` 白底 56px，含 Logo + 首页/关于/申请收录），底部白底页脚，全部为「非玻璃」的旧样式（`bg-white/80 backdrop-blur-sm`）。
- `src/views/frontend/HomeView.vue`：`BackgroundImage` + 居中的 `DateTimeDisplay` + 标语 h2（`homeTitle`，默认「上网，从这里开始！」）+ `SearchBox` + 分类卡片区 + `BackToTop`。
- `src/components/frontend/SearchBox.vue`：白底圆角搜索框 + 蓝色搜索按钮 + 引擎选择按钮（选中态 `bg-blue-100`，未选中 `bg-gray-100`，无边框统一）。
- `src/components/frontend/DateTimeDisplay.vue`：当前是「时间大、日期小」居中显示，背景旧。
- `src/components/frontend/BackgroundImage.vue`：有背景图才显示图，无图时仅 `bg-white/70` 白色蒙层（会压死玻璃质感）。
- `src/components/frontend/LinkCard.vue`：白底卡片。
- `src/views/frontend/AboutView.vue / ApplyView.vue`：白色卡片，未含背景图，页面为纯白底。
- `src/style.css`：仅 `@import "tailwindcss";`。
- `src/views/admin/ConfigView.vue`：站点配置表单（`config` reactive 对象 + `configKeys` 循环读写），可在此新增「前台主题」字段。
- `src/stores/home.ts`：`fetchData()` 已读取 `siteConfig`（含 `background` 等配置）；`BackgroundImage` 的 `bgUrl` 由 HomeView 从 `store.siteConfig.background` 传入。
- 后台 `AdminLayout.vue` 为独立深色侧边栏 + 浅色内容区，本次不重构（仅 ConfigView 加一个字段）。

## 三、目标布局结构

```
┌──────────────────────────────────────────────────────┐
│ [logo 网站名 首页|关于|申请收录]（左上角玻璃胶囊） 2026年08月31日 星期日（右上，滚动后消失）│
│                                                    20:31（时间始终可见/吸顶条右侧）│
│                                                      │
│              （slogan 已删除）                          │
│        ┌──────────────────────────┐                  │
│        │ 🔍 使用 百度 搜索……  [搜索] │  ← 毛玻璃搜索条（居中）│
│        └──────────────────────────┘                  │
│           [百度] [必应] [谷歌]（引擎按钮，等宽边框）        │
│                                                      │
│  分类标题 ─────────────────────────（玻璃分隔线）        │
│   ┌────┐ ┌────┐ ┌────┐           玻璃卡片网格          │
│   └────┘ └────┘ └────┘                                │
│                 页脚（毛玻璃）                          │
└──────────────────────────────────────────────────────┘

滚动后（scrollY > 阈值）：
- 左上胶囊导航整体向上淡出（原顶部导航区域完全消失）
- 右上日期消失；时间移入顶部吸顶搜索条右侧，始终可见
- 搜索条由居中窄条变为顶部通栏吸顶条（变宽、高度与导航胶囊持平≈48px）
- 吸顶条下方一层「隐形阻挡层」（渐变遮罩+模糊），图标下移时不穿透显示
```

## 四、Proposed Changes（逐文件）

### 1. `src/style.css` — 主题变量 + 玻璃工具类

**Why**：所有组件的多主题适配都依赖一套 CSS 变量。

**What**：
- 定义 `:root, [data-theme='light']` 与 `[data-theme='dark']` 两套变量：
  - `--glass-bg`（浅 `rgba(255,255,255,0.12)`；深 `rgba(8,12,32,0.42)`）
  - `--glass-bg-strong`（吸顶条/选中态用，浅 `rgba(255,255,255,0.22)`；深 `rgba(8,12,32,0.6)`）
  - `--glass-border`（浅 `rgba(255,255,255,0.18)`；深 `rgba(255,255,255,0.14)`）
  - `--glass-blur: 20px`、`--glass-saturate: 180%`
  - `--glass-shadow: 0 8px 32px rgba(0,0,0,0.12)`（深色调 `0 8px 32px rgba(0,0,0,0.5)`）
  - `--glass-text: #ffffff`、`--glass-text-soft`（`rgba(255,255,255,0.78)`）、`--glass-text-faint`（`rgba(255,255,255,0.55)`）
  - `--glass-hover`、`--glass-selected`（引擎选中高亮）、`--glass-shield`（隐形阻挡层底色）
  - 页面渐变兜底背景色：`--page-bg-1/2/3`（浅色：深邃蓝紫极光；深色：近黑深蓝）
- 定义基础类（避免 Tailwind v4 任意值语法风险、多处复用）：
  - `.glass`：`background:var(--glass-bg); border:1px solid var(--glass-border); border-radius:16px; box-shadow:var(--glass-shadow); backdrop-filter:blur(var(--glass-blur)) saturate(var(--glass-saturate)); -webkit-backdrop-filter:...`
  - `.glass-strong`（吸顶条）
  - `.glass-card`（网格卡片，radius 14px + hover 用 `--glass-hover`）
  - `.glass-text / .glass-text-soft / .glass-text-faint`
  - `.glass-chip`（引擎按钮：等宽 1px 边框，选中 `--glass-selected` 高亮+文字全白，未选中透明边框+柔和文字，`flex items-center justify-center` 垂直居中）
- `body` 基础：`color:var(--glass-text)`，并在 body 上铺 `--page-bg-*` 渐变兜底（`min-height:100vh` 渐变），保证无背景图时玻璃质感依然成立。

### 2. 新增 `src/composables/useDateTime.ts`

**Why**：日期时间需要在「首屏右上主角块」与「吸顶条右侧小时间」两处复用，避免重复定时器逻辑（保持代码整洁）。

**What**：导出 `useDateTime()`，返回 `timeStr`（HH:MM）、`dateStr`（`x年x月x日` 格式）、`weekdayStr`、内部 `setInterval` 更新；`DateTimeDisplay` 与 HomeView 吸顶小时间共用。仅为展示逻辑抽取，无功能变更。

### 3. 新增 `src/stores/theme.ts`（Pinia）

**Why**：主题需在 `main.ts` 挂载前同步应用（防闪烁），并在 ConfigView 保存后即时生效。

**What**：
- `theme = ref(localStorage.getItem('site_theme') || 'light')`
- `apply(theme)`：设置 `document.documentElement.dataset.theme`，写入 localStorage。
- `syncFromConfig(value)`：若后台配置存在且与当前不同则 `apply`。
- `init()`：挂载前同步 `apply(theme.value)`。

### 4. `src/main.ts`

- `useThemeStore().init()` 在 `app.mount()` 之前调用（同步设置 `data-theme`，默认 light，无白闪）。

### 5. `src/views/frontend/FrontendLayout.vue` — 导航胶囊 + 背景迁移 + 页脚玻璃

**Why**：需求要求「删除原顶部横向导航条」「导航收缩至左上角」「滚动时顶部导航区域完全消失」，且背景应全局生效（About/Apply 页也需要玻璃氛围）。

**What**：
- 删除原 `<header>` 全宽导航条。新增 `fixed top-4 left-4 z-40` 玻璃胶囊（`.glass`）：Logo + 站名 + 三个链接（首页/关于/申请收录），链接 hover 用 `--glass-hover`，文字 `var(--glass-text)`。
- 滚动监听（`scrollY > 64`）时对胶囊加 `.nav-hide`（`translateY(-130%) + opacity 0`，`transition` 0.4s），实现「原顶部导航区域完全消失」。
- 将 `BackgroundImage` 从 HomeView 移入本组件根节点 `<BackgroundImage :bg-url="bgUrl" />`；`bgUrl` 在此处的 `config.getAll()` 里一并读取 `background`。
- 页脚改为 `.glass` 顶部斜边玻璃（半透明 + 边框 + 模糊），文字 `--glass-text-faint`，保留 ICP 链接样式微调。
- 配置加载完成后调用 `useThemeStore().syncFromConfig(config['theme'])`。

### 6. `src/components/frontend/BackgroundImage.vue` — 渐变兜底 + 图覆盖

**Why**：核心视觉要求「背景提供一套渐变或图片兜底，确保无背景图时毛玻璃质感依然存在」。

**What**：
- 底层始终渲染固定渐变（`fixed inset-0 -z-10`），渐变取自 `--page-bg-1/2/3`（跟随主题变量自动切换浅/深），另叠加一两个径向高光（极光感）。
- 有 `bgUrl` 时在上面叠加 `bg-cover bg-center` 图 + 深色半透明渐变蒙层 `rgba(10,15,40,0.35)` 保证白字可读。
- **删除**原 `bg-white/70` 蒙层（它正是压死玻璃质感的原因）。

### 7. `src/components/frontend/DateTimeDisplay.vue` — 首屏右上日期时间

**Why**：需求四。

**What**：
- 结构改为：日期在上（`xx年xx月xx日 星期x`，字号略大约 `text-xl/2xl`，`--glass-text`），时间在下（`font-weight:600` + `letter-spacing` 略微加宽，`--glass-text`）。
- 用 `useDateTime()` 替换内部逻辑（dateStr 转 `2026年08月31日` 格式）。
- 位置/显隐交给 HomeView 外层控制（本组件保持纯展示）。

### 8. `src/components/frontend/SearchBox.vue` — 玻璃样式 + 引擎按钮 + 吸顶态

**Why**：需求六（6.1 玻璃变量；6.2 引擎按钮去勾选、等宽边框、高亮选中、文字垂直居中；6.3 滚动缩放）。

**What**：
- 新增 prop `stuck: boolean`。
- 容器：`.glass` + `rounded-full`，搜索图标、输入框、按钮全部用玻璃变量；输入文字 `var(--glass-text)`、placeholder `--glass-text-soft`；搜索按钮 `.glass-strong`（白字，hover 增亮）。
- **引擎选择按钮（6.2）**：统一 1px 边框（未选中 `border:1px solid transparent`，选中 `border:1px solid var(--glass-border)` + `background:var(--glass-selected)` + 文字全白 + 轻微高光）；所有按钮 `flex items-center justify-center` 垂直居中；去掉任何 ✓ 图标。
- **吸顶态（6.3）**：`stuck` 时外层自动`position:fixed; top:0; left:0; right:0; z-40; padding:8px 16px; background:var(--glass-bg-strong)` + 底部边框，内部搜索行从居中小圆角过渡为顶部通栏（`max-width:100%`、高度≈48px 与导航胶囊持平），引擎按钮行隐藏；`transition: all .35s ease`。HomeView 将吸顶小时间放在该条右侧。

### 9. `src/views/frontend/HomeView.vue` — 首屏重构 + 滚动行为

**Why**：需求三（删标语、精简首屏）、四（日期时间位置）、六.3（吸顶）、七（内容区统一）。

**What**：
- **删除**标语 h2（“上网，从这里开始！”），保留数据读取代码不动（仅模板层面移除）。
- 移除本页 `BackgroundImage`（已迁至 FrontendLayout）。
- 「固定右上日期时间块」：`fixed top-5 right-6 z-40 text-right select-none`，包裹 `<DateTimeDisplay>`；滚动后该块 `opacity-0 translate-y-[-8px]`（日期随之消失）——用 `scrolled` ref 控制。
- 搜索区：外层 `search-shell` 包裹 `<SearchBox :stuck="scrolled" />` + 吸顶小时间 `<span class="glass-text font-semibold tracking-[0.25em] tabular-nums">{{ timeStr }}</span>`（`scrolled` 时才显示，位置在搜索条右侧）。
- **隐形阻挡层**：`<div class="sticky-shield">` `fixed top-0 inset-x-0 h-16 z-30`，`background:var(--glass-shield)`（渐变到透明）+ `backdrop-filter: blur(20px) saturate(180%)`，仅 `scrolled` 时显示；层级在吸顶条（z-40）之下、正文之上，防止分类图标滚动穿透到吸顶条背景。**不额外加白色底条**，底部以渐变自然融合。
- 滚动监听：`window.addEventListener('scroll', ..., { passive:true })`，阈值 `scrollY > 60`；`scrolled` 传入 `DateTimeDisplay`/`SearchBox`。
- 分组标题：`.glass-text` 大号 + 底部 `1px solid var(--glass-border)`；骨架屏占位改为 `.glass` 半透明占位块；空状态文字用 `--glass-text-faint`。
- 首屏垂直布局：`min-h-[calc(100vh-XX)] flex flex-col items-center justify-center`，留白拉开主次。

### 10. `src/components/frontend/LinkCard.vue` — 玻璃卡片

**Why**：需求七（内容区视觉与首屏/侧栏统一：玻璃感、圆角、阴影）。

**What**：`bg-white rounded-lg` → `glass-card`（`var(--glass-bg)` + `1px var(--glass-border)` + `14px` 圆角 + `var(--glass-shadow)`）；hover `background:var(--glass-hover)` + `scale(1.03)` 保留；标题 `var(--glass-text)`、描述 `--glass-text-faint`；图标兜底块由 `bg-blue-100 text-blue-600` 改为玻璃高亮块（`var(--glass-bg-strong)` + 白字）。

### 11. `src/views/frontend/AboutView.vue` / `ApplyView.vue` — 卡片玻璃化

**Why**：共用 FrontendLayout 后背景为玻璃氛围，白色硬卡片需同步（需求「所有组件适配多主题」「视觉统一」）。

**What**：外层卡片 `bg-white/80` → `.glass`；标题/正文文字用 `.glass-text`/`--glass-text-soft`。表单输入框（URL/图标/验证码等）保持中性白底不透明输入（保证可读性，属表单可读性兜底，不在需求列出的必须适配组件内）。Apply 页告警蓝条保留原样式（语义色）。

### 12. `src/views/admin/ConfigView.vue` — 设置面板新增「前台主题」

**Why**：用户确认主题切换入口放在 /admin 设置面板。

**What**：在「基本信息」区块新增下拉「前台主题」：`config.theme`（`light` 毛玻璃浅色 / `dark` 毛玻璃深色），加入 `config` reactive 默认值 `theme: 'light'`（`configKeys` 自动覆盖加载与保存）；`saveAll` 成功后调用 `useThemeStore().apply(config.theme)` 即时生效，便于管理员预览。

## 五、Assumptions & Decisions（假设与决策）

1. 主题入口仅放 /admin 设置面板（用户已确认），前台导航胶囊不放主题按钮。
2. 主题切换只影响前台视觉；后台管理界面（AdminLayout）保持原样，仅 ConfigView 增加字段。
3. 引擎按钮行在吸顶态隐藏（保持吸顶条克制、防止元素堆砌），搜索交互不受影响。
4. About/Apply 表单输入框保持白色不透明（可读性兜底），不强制跟随玻璃透明。
5. 404 页（NotFoundView）为独立极简页，不纳入本次重构。
6. `homeTitle` 配置字段保留在 store 读取逻辑中不删除（仅首页模板不再渲染），避免无谓功能改动。
7. 主题不做「跟随系统自动切换」，严格二选一（用户已确认双主题）。

## 六、Verification（验证步骤）

1. 类型检查 + 构建：`npx vue-tsc -b && npx vite build`（build 产物 `dist/`；验证 `base:'./'` 相对路径、Hash 路由、无新增硬编码 env）。
2. `npm run dev`（或 `vite preview`）启动，浏览器走查：
   - 无背景图时渐变兜底 + 玻璃质感成立；配置背景图后图 + 蒙层显示正常。
   - 首屏：标语消失；日期/时间右上一大一小；导航胶囊在左上角。
   - 向下滚动：导航胶囊淡出、日期消失、时间仍可见（移入吸顶条右侧）、搜索条变宽吸顶且高度与胶囊持平、无白色底条、图标下滚不穿透吸顶条（隐形阻挡层生效）。
   - 引擎按钮：无 ✓、等宽边框、选中高亮、文字垂直居中，切换正常、搜索功能正常。
   - 卡片/分组/页脚玻璃样式统一；移动端（窄屏）响应式正常。
   - /admin 设置面板：保存「前台主题=深色」后返回前台为深色玻璃、组件全部适配；恢复浅色正常。
3. 回归检查：分类链接点击跳转、统计埋点、About/Apply 页表单（验证码/提交）、后台其它页面不受影响。

## 七、Out of Scope（不在本次范围）

- 后台管理界面视觉重构（除 ConfigView 新增主题字段外）。
- 任何功能/数据流改动、后端与 Schema 改动、第三方库新增。
- 搜索引擎管理、死链检测、统计等既有功能行为。
